# Landing page — Gestão de Ordens de Serviço

Landing page estática, responsiva e sem dependências para apresentar um aplicativo de gestão de ordens de serviço.

## Executar localmente

```powershell
npm.cmd run dev
```

Abra `http://localhost:4173`.

## Antes de publicar

Edite `siteConfig` em `app.js`:

- `whatsapp`: número internacional apenas com dígitos (por exemplo, `5511999999999`);
- `email`: e-mail de contato.

O nome provisório e os textos ficam centralizados principalmente em `index.html`. A página não anuncia funcionalidades, preços ou compatibilidades não confirmados.
